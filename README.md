## 쓰는 법
**바로 열기** → https://hotae84.github.io/soc/ (설치·다운로드 없이 브라우저에서 바로 실행)

내려받아 쓰려면:
1. 초록 **Code ▾ → Download ZIP**으로 전부 내려받아 압축을 풀고, `index.html`을 엽니다.
2. 장 진행 중에는 **실습**, 장이 끝나면 **퀴즈**. 모션판·기본형은 내용이 같으니 편한 쪽을 쓰면 됩니다.
3. 파일을 한 폴더에 둔 채로 쓰셔야 이동 링크가 이어집니다. 외부 연결·저장·전송은 없습니다.

자세한 안내는 [`quiz/README.md`](quiz/README.md)에 있습니다.
